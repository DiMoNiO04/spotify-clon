Создал полноценный клон Spotify на React и MobX с нуля. Музыкальный плеер с воспроизведением, паузой, перемоткой треков,
плейлистами и синхронизацией слов песни. Настроил Tailwind для стилей, добавил тёмную тему и плавные анимации.
Использовал TypeScript для типизации, Vite для сборки, lucide-react для иконок. Стэк: React, MobX, TypeScript, Tailwind,
Vite, nuqs.
